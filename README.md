# Andreos Play

Andreos Play — Android-приложение, в котором собраны все игры Andreos:

- Дорога в океан
- Бутербашня
- Кимчи-кафе Глеба Ли
- HackQuest

Современное меню с анимациями, анимированная заставка, иконка под тему телефона (Android 13+).
Подстраивается под любой экран: телефоны, планшеты, складные, вертикально и горизонтально.
Игры открываются на весь экран и работают без интернета.

## Скачать

Последняя сборка всегда здесь: **[AndreosPlay.apk](../../releases/latest/download/AndreosPlay.apk)**.
Открой ссылку на телефоне, скачай файл и установи (Android попросит разрешить установку из этого источника).

## Как это устроено

- `app/` — приложение на Kotlin: экран-меню и WebView, в котором запускаются игры.
- `app/src/main/assets/index.html` — меню с карточками игр.
- `scripts/fetch_games.sh` — при каждой сборке скачивает свежие версии игр из их репозиториев
  и кладёт рядом three.js и Pyodide, чтобы всё работало офлайн.
- `.github/workflows/build.yml` — GitHub сам собирает APK при каждом пуше в `main`
  (или по кнопке Run workflow во вкладке Actions) и обновляет релиз `latest`.

Чтобы в APK попали изменения в играх, достаточно запустить сборку заново (Actions → «Сборка APK» → Run workflow).

### Добавить новую игру

1. Добавь имя репозитория в список `GAMES` в `scripts/fetch_games.sh`.
2. Добавь карточку в массив `games` в `app/src/main/assets/index.html`.
